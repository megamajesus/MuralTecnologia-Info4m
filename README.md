## Objetivo
Aplicação web desenvolvida para a disciplina de Programação para Internet, com o intuito de consumir a API pública da Beeceptor, manipular o DOM de forma assíncrona, aplicar filtros de pesquisa e tratar os estados da interface.

## Como executar
1. Baixe e descompacte a pasta do projeto (que estara em. zip)
2. Abra o arquivo `index.html` em qualquer navegador web moderno.
3. Clique no botão **"Carregar publicações"** para realizar a requisição HTTP.

## API utilizada
https://json-placeholder.mock.beeceptor.com/posts
